# Bioinformatics Learning Journey- Second Repo

This repository contains my learning progress in Python for Bioinformatics, focusing on NumPy, Pandas, and Seaborn for biological data analysis and visualization.

---

## What I Covered

## Day 8 — NumPy Basics
- Arrays and slicing
- Basic operations on sequences
- GC content calculation from DNA sequences

## Day 9 — Pandas Basics
- Creating and reading DataFrames (read_csv)
- Filtering gene expression data
- Basic grouping using groupby

## Day 10 — Pandas Advanced
- Merging gene tables
- Sorting data by values
- Applying functions to columns
- Cleaning missing data

## Day 11 — Seaborn Visualization
- Heatmaps for gene expression matrices
- Boxplots and scatter plots
- Visual comparison of gene expression patterns

## Day 12 — Biopython Basics (SeqIO + Seq)
- Using Seq object for DNA sequence operations
- Complement, reverse complement, transcription, translation
- FASTA file reading using SeqIO
- Parsing multiple sequences from FASTA
- Basic sequence analysis (length, GC content)
- Working with SeqRecord (id + sequence handling)

## Day 13 — Biopython Entrez (NCBI Access)
- Using Entrez to access NCBI databases
- Fetching sequences using accession numbers
- Downloading FASTA data programmatically
- Parsing fetched data with SeqIO
- Searching genes using esearch
- Basic sequence analysis from NCBI data (length, GC content)
